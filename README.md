Hangman Multi-Word Puzzle Game
Overview

This is a web-based Hangman-style puzzle game where players guess letters to complete multi-word phrases.
The game displays phrases in a grid layout, spaces between words are visible, and players fill in letters by guessing.

The game is designed using HTML, CSS, and JavaScript.

Features

🎮 Random multi-word phrases

🧩 Grid layout with spaces for words

⌨️ Letter input for guessing

✅ Correct guesses reveal letters in all positions

🎉 Win message when the phrase is completed

🌈 Game-style UI with colorful grid and buttons

Technologies Used

HTML – Structure of the game

CSS – Styling and grid layout

JavaScript – Game logic (random phrases, letter guesses, win detection)

Setup Instructions

Download or clone the repository.

Make sure you have the following files in the same folder:

index.html

style.css

script.js

Open index.html in any modern web browser.

How to Play

The game will display a grid with underscores representing letters in a random phrase.

Spaces between words are already visible.

Enter a single letter in the input box and click Guess.

Correct guesses will reveal the letters in all positions.

Incorrect guesses show a message (currently unlimited attempts).

The game ends with a win message when all letters are guessed correctly.
